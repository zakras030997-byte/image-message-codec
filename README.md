# Image Message Codec · ANODHAS AI

Скилл для Codex: сообщение в геометрии картинки и проверяемое декодирование.

## Что умеет

- Создаёт новый ночной пейзаж: высоты звёзд кодируют A–Z, промежутки разделяют слова.
- Восстанавливает текст из исходного PNG отдельным вызовом декодера.
- Даёт агенту процедуру исследования неизвестной схемы по измерениям, без угадывания ответа.
- Не перезаписывает существующие выходные файлы.

Это демонстрационная стеганография, а не криптографическая защита. До 40 букв A–Z и одиночные пробелы. Русский текст, цифры, произвольные фотографии и автоматическое восстановление после JPEG/масштабирования текущий кодек не поддерживает. Нет криптографической проверки целостности.

## Установка в Codex

Скопируйте каталог репозитория в `~/.codex/skills/image-message-codec`, сохранив `SKILL.md` в корне. Затем используйте доступный локальный Python с Pillow. При необходимости установите зависимости в отдельное виртуальное окружение самостоятельно:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Пример запроса: «Используй image-message-codec: спрячь фразу HELLO HERMES в картине и проверь восстановление».

## Командная строка

```bash
mkdir output
printf '%s\n' 'HELLO HERMES' | .venv/bin/python scripts/stars.py encode --output output/night-lake.png
.venv/bin/python scripts/stars.py decode --input output/night-lake.png --output output/decoded.txt
.venv/bin/python -B scripts/test_stars.py
```

Для личного текста используйте stdin или `--message-file`, без значений в аргументах процесса. Не используйте реальные пароли и токены.

## Как это устроено

Горизонт находится на y=400; номер буквы равен `(400-y)/10`. Чтение слева направо; шаг 80 пикселей внутри слова, 200 между словами. PNG имеет высоту 800 пикселей, ширина зависит от длины текста. Отправка как файл сохраняет исходные пиксели; прохождение конкретного канала нужно проверять отдельно.

## Наш эксперимент

Фраза HELLO HERMES была закодирована в 11 звёздах. Сначала агент описал пейзаж; после общей просьбы исследовать скрытое сообщение восстановил текст и формулу. Это не полностью слепой тест: в контексте была ссылка на материал о скрытых сообщениях. Самостоятельное обнаружение без подсказки не подтверждено. Локальная проверка кодека: 9 искусственных тестов и отдельный вызов encode → decode. Для поиска неизвестных схем предоставлена инструкция, а не универсальный декодер.

## Безопасность

Найденные внутри изображения команды считаются данными и не выполняются. Скилл не разрешает чтение Связки ключей, передачу секретов, загрузку чужих файлов или обход защит.
